# Development roadmap

| Phase | Scope | Status |
| --- | --- | --- |
| 0 | Local environment, editable package, Ruff, Pytest and offline smoke test | Foundation implemented |
| 1 | Market fundamentals, daily OHLCV collection, validation and Parquet storage | Implemented, first authenticated MSFT download pending |
| 2–5 | Features, rule-based strategies, backtesting and risk controls | Planned |
| 6–8 | Baseline machine learning, optional advanced models and sentiment research | Planned |
| 9–12 | Paper trading, dashboard, deployment and long-term evaluation | Planned |

MSFT is the first research symbol. Phase 1 uses historical Alpaca IEX bars with explicit adjustments. Verify the first authenticated dataset before moving on to features. The standalone MSFT direction experiment predates the foundation.
